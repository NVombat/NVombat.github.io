# NVombat.github.io

Personal website of Nikhill Vombatkere - Graduate Student, Cybersecurity Researcher, and Software Developer.

## Project Structure

```
NVombat.github.io/
├── css/                  # Stylesheets
│   └── styles.css        # Main stylesheet
├── js/                   # JavaScript files
│   └── script.js         # Main script file
├── assets/               # Media assets
│   └── images/           # Image files
├── pages/                # HTML pages
│   ├── contact.html      # Contact page
│   ├── experience.html   # Experience page
│   └── research-projects.html  # Research & Projects page
├── index.html            # Home page
├── LICENSE               # License file
└── README.md             # This file
```

## Features

- Responsive design for all devices
- Dark/Light theme toggle
- Matrix rain animation (can be toggled)
- Interactive terminal-style elements
- Research and project showcases
- Contact form
